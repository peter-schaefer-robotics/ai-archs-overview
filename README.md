# Perceptron to World Models

A reference table of 69 AI model architectures in the order they arrived, from the
1943 McCulloch-Pitts neuron to the 2026 frontier.

Each row gives the mechanism, the technological breakthrough, what it is used for,
who made it popular, where it is strong and weak, and a citable source.
The 23 architectures with the widest adoption afterwards are marked and plotted on
a timeline with a deliberate scale break, because half of them fall after 2012.

Live page: https://peter-schaefer-robotics.github.io/ai-architectures/
